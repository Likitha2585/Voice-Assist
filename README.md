# Voice Assist — AI-Powered Voice Shopping Assistant

Voice Assist is a full-stack voice-enabled shopping application that provides
an interactive way for users to discover and interact with products using
voice-based input.

The application combines a React.js frontend with a Node.js backend to provide
a responsive and conversational shopping experience.

---

## ✨ Features

- 🎙️ Voice-based shopping interaction
- 🔎 Natural-language product discovery
- 🛍️ Product browsing and shopping workflows
- 💬 Interactive conversational experience
- ⚡ Responsive user interface
- 🔗 Frontend-backend API integration
- 📦 Modular frontend and backend architecture
